gatsby-dark-mode
================

A CMS language migration utility for moving multilingual content between major versions.

Tip: Use a spreadsheet to track all translation entries — verify each one is migrated, published, and correctly linked.

## new-personal-site
1. Dump your database before starting (via phpMyAdmin or a backup tool like Akeeba Backup).
2. Download and manually install the language extension on the target installation via the admin installer.
3. Run the migration script step by step.
4. Manually publish articles and set language translation to 'YES', linking each translation to its original entry in the language table.
